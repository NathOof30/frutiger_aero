# Frutiger Aero - ClearSky Archiving

Projet front-end realise avec Vite, Tailwind CSS et une direction visuelle inspiree de l'univers Frutiger Aero / Windows 7.

## Prerequis

- Node.js
- npm

## Lancer le projet

1. Installer les dependances:

npm install

2. Lancer le serveur de developpement:

npm run dev

3. Construire la version de production:

npm run build

4. Previsualiser le build de production:

npm run preview
